# AquaDose

**Estimative Index (EI) aquarium dosing calculator.**

AquaDose is an offline mobile utility designed specifically for planted freshwater aquarium hobbyists. It eliminates guesswork and complex spreadsheets by calculating precise dry salt fertilizer dosages using the **Estimative Index (EI)** methodology.

## Key Features

* **Dry Salt Calculations:** Get exact gram measurements for KNO3, KH2PO4, K2SO4, and Plantex CSM+B or alternative micro-mixes.
* **Net Water Volume:** Accounts for hardscape, substrate displacement, and equipment volume to prevent accidental overdosing.
* **Target PPM Management:** Dial in specific nutrient ratios to support rapid plant growth while starving nuisance algae.
* **100% Offline Core:** All dosage calculations execute locally on your device with no mandatory account creation or cloud dependencies.
